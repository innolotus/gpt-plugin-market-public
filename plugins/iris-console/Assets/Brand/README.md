# Iris Brand Assets

This directory contains the provisional Iris mark used by responsive HTML reports.

## Files

- `iris-logo-mark-master.png`: 1254×1254 RGBA source asset.
- `iris-logo-mark-report.png`: 192×192 RGBA report asset embedded by `answer-me-with-html`.

Use the compact report asset for generated reports. Keep the master only for future brand refinement and export work.

The mark combines an iris/aperture, a home silhouette and a location point. It contains no text, remains legible at small sizes and uses transparency so it works with light and dark report modes.

The asset was generated for Iris on 2026-10-13 with OpenAI image generation. Treat it as provisional MVP branding until a formal brand review replaces or approves it.
